# My Toolkit

A free, simple browser toolkit that brings five everyday tools into one page. It runs entirely in the browser, with no sign-up, no installation, and no server.

**Live site:** https://saniachavan95-sudo.github.io/toolkit/

## Tools

- **Stopwatch:** Precise timing with an analog dial, laps with split times and keyboard shortcuts (Space to start or stop, R to reset).
- **Timer:** Type a time such as 90, 2:30, or 1:02:00, then count down with a dial that shows the time left.
- **Age:** Find your exact age in years, months and days, plus your total days lived and the days until your next birthday.
- **Days Between:** Calculate the gap between two dates and times, shown as years, days, hours and minutes.
- **Unit Converter:** Convert length, weight and temperature. Type in either box and the other one updates.

## How to use

1. Open the live site or open index.html in your browser.
2. Click a tool on the landing page.
3. Use the **Back** button at the top left to return to the landing page.

## Built with

- HTML for the page structure
- CSS for the layout, colors, and custom cursors
- JavaScript for the timing, date, and unit calculations (SVG is used for the dials)


## Project structure

```
toolkit/
```

## Running it locally

1. Download or clone this repository.
2. Double-click index.html to open it in Chrome, Edge, or Firefox.

No build step or installation is needed.
